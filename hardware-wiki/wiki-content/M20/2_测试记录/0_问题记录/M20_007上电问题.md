# M20_007 上电问题

## 基本信息

| 项目 | 内容 |
|------|------|
| **板卡型号** | M20_SOC_V1.0 |
| **SN** | 2602120010007 |
| **问题类型** | 上电异常 |
| **日期** | 2026-07-03 |
| **状态** | ✅ 已解决 |

## 故障现象

- VDD_SOC = 0V ❌ 异常
- VCC_S4_P0V75_PG = 3.3V ✅ 正常
- STR_PWR_EN = 3.3V ✅ 正常
- 其余前级电压均正常

## 调试过程

### 定位 VDD_SOC 异常

U38 (BPD95025) 是 CPU & SOC PMIC，EN2 (pin 14) 控制 VDD_SOC 输出。EN2 的供电路径：

`
VCC_S4_P0V75_PG(3.3V) → R452(0Ω) → VS_EN → U38 EN2 (pin 14)
STR_PWR_EN(3.3V) → D3 → VS_EN (冗余路径)
`

测量发现：

| 信号 | 期望值 | 实测值 | 结果 |
|------|--------|--------|------|
| VCC_S4_P0V75_PG | 3.3V | 3.3V | ✅ |
| STR_PWR_EN | 3.3V | 3.3V | ✅ |
| U38 EN2 (pin 14) | 3.3V | 0V | ❌ |

VCC_S4_P0V75_PG = 3.3V 但 U38 pin 14 = 0V，说明 R452 两端存在开路。同时 STR_PWR_EN 也未通过 D3 到达 EN2。

### 进一步排查

对比正常板卡，发现 R452、D3、R337 三个元件缺失。

## 根本原因

**物理损坏：R452、D3、R337 被磕掉（脱落）。**

| 损坏元件 | 位号 | 功能 | 影响 |
|---------|------|------|------|
| R452 | 0Ω 电阻 | VCC_S4_P0V75_PG → U38 EN2 | U38 EN2 = 0V，VDD_SOC 无输出 |
| D3 | 双二极管 | STR_PWR_EN → EN2 冗余路径 | R452 开路后无法通过 STR_PWR_EN 补救 |
| R337 | 电阻 | 其他功能 | 额外功能缺失 |

## 解决方案

补焊 R452、D3、R337，上电正常。

## 经验总结

1. **M20 上电链路关键信号**：VCC_MCU_P3V3 → VIN_PWR_ON → VCC_P12V0_R → VCC_S4_P0V75 → VCC_S4_P0V75_PG → U38 EN2 → VDD_SOC
2. **BPD95025 (U38) 双路使能**：EN1 (VC_EN) 控制 VDD_CPU，EN2 (VS_EN) 控制 VDD_SOC，缺一不可
3. **板卡磕碰检查**：收到板卡后先目检贴片元件是否完整，特别是 0Ω 电阻和二极管等小封装器件
