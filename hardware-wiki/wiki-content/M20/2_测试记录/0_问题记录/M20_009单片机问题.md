# M20_009 单片机问题

## 基本信息

| 项目 | 内容 |
|------|------|
| **板卡型号** | M20_SOC_V1.0 |
| **SN** | M20_009 |
| **问题类型** | 上电异常（MCU不输出VIN_PWR_ON） |
| **日期** | 2026-07-03 |
| **影响范围** | 整板后级电压全部异常 |
| **状态** | ✅ 已解决 |

## 故障现象

- VCC_SRC = 12V ✅ 正常
- VCC_MCU_P3V3 = 3.3V ✅ 正常
- VCC_P12V0_R = 0.7V ❌ 异常（应为12V）
- 依赖 VCC_P12V0_R 的所有后级电压均异常：
  - VCC_S1_P5V0、VCC_S1_P3V3、VCC_S2_P3V3
  - VCC_S3_P1V8、VCC_S4_P1V8、VCC_S4_P0V75
  - VCC_S6_P1V8、VCC_S6_P1V05、VCC_S7_P0V6、VCC_S7_P1V2
- MCU 芯片可被 ST-Link 正常识别

## 调试过程

### 1. 定位 VCC_P12V0_R 异常

VCC_P12V0_R 由 U30 (P-MOSFET AGM30P08AP) 控制导通，MCU 通过 VIN_PWR_ON 信号驱动栅极：

```
MCU VIN_PWR_ON → R274(0Ω) → Q16(N-MOS 2N7002) G极
                                         ↓
                            Q16导通 → U30 G极拉低 → U30导通 → VCC_P12V0_R=12V
```

实测 MCU 的 VIN_PWR_ON = 低电平（0V），导致 Q16 不导通、U30 G极被 R275 上拉至高电平、U30 截止，VCC_P12V0_R 仅 0.7V（漏电电压）。

### 2. 检查 MCU 基本条件

| 条件 | 测量点 | 实测值 | 结果 |
|------|--------|--------|------|
| 供电 | VCC_MCU_P3V3 | 3.3V | ✅ |
| 复位 | NRST (引脚7) | 高电平 | ✅ |
| 晶振 | OSC_OUT | 8MHz 起振 | ✅ |
| 启动模式 | BOOT0 (引脚44) | 低电平 | ✅ |

MCU 基本工作条件全部满足。

### 3. 检查 MCU 固件

- ST-Link 可正常识别 MCU 芯片
- 读取 Flash 内容保存为 bin 文件
- 与正常板卡 MCU 固件对比，**bin 文件无差异**

### 4. 分析 MCU 输入信号

M20 上电序列中，MCU 需要外部触发才会输出 VIN_PWR_ON。

MCU 关键输入信号分析：

| 信号 | MCU引脚 | 来源 | 上电时可用性 |
|------|---------|------|-------------|
| POWER_BTN_N | PA11 (32脚) | 底板连接器 L61，经 10K 上拉到 VDD_3V3_SYS | **唯一可用触发信号** |
| MCU_MOD_BRD_ON_N | - | 经 U25 电平转换，需 VCC_S1_P3V3 供电 | ❌ VCC_S1_P3V3=0V |
| MCU_VDDIN_PWR_BAD | - | 经 U25 电平转换，需 VCC_S1_P3V3 供电 | ❌ VCC_S1_P3V3=0V |
| MCU_FORCE_REC_N | - | **MCU 输出信号**，非输入 | — |
| MCU_SYS_RESET_N | - | **MCU 输出信号**，非输入 | — |
| MCU_MODULE_SHDN | - | **MCU 输出信号**，非输入 | — |

**结论：上电初期，MCU 唯一能接收的触发信号是 POWER_BTN_N。** 其余输入信号依赖的电平转换芯片（U25 等）需要 VCC_S1_P3V3 供电，而 VCC_S1_P3V3 由 VCC_P12V0_R 产生——这正是尚未输出的电压。

### 5. 测量 POWER_BTN_N

底板原理图（WS-MDN-706）第3页：

```
VDD_3V3_SYS(3.3V) → R1(10K) → L61(POWER_BTN_N) → M20模块 → MCU PA11(引脚32)
```

| 测试点 | 期望值 | 实测值 | 结果 |
|--------|--------|--------|------|
| MCU 引脚32 (PA11) | 3.3V | **1.8V** | ❌ |

STM32F103C8T6 逻辑电平门限：
- VIH（最小高电平）= **2.0V**
- 1.8V 落在不确定区间（0.8V~2.0V），MCU 无法可靠识别为高电平

## 根本原因

**MCU 固件异常。** 虽然 bin 文件对比无差异，但重新烧录后恢复正常。可能原因：

1. Flash 内容存在不稳定位（bit instability），读取时正确但执行时出错
2. Flash 存在间歇性读取错误，影响 MCU 正确识别 POWER_BTN_N 并执行上电逻辑

## 解决方案

重新烧录 MCU 固件（STM32F103C8T6），上电正常。

## 经验总结

1. **M20 上电依赖链**：VCC_SRC(12V) → VCC_MCU_P3V3(3.3V) → MCU 启动 → POWER_BTN_N 触发 → VIN_PWR_ON 输出 → VCC_P12V0_R(12V) → 后级全部电压
2. **POWER_BTN_N 是唯一上电触发源**：上电初期只有该信号可由底板直接驱动到 MCU，其他输入信号依赖的电平转换芯片尚未供电
3. **MCU bin 对比一致不代表固件正常**：存在 Flash 不稳定导致执行异常的可能，重烧固件是有效的排查手段
4. **上电异常的排查优先级**：供电电源 → 时钟 → 复位 → 关键使能信号 → 固件
