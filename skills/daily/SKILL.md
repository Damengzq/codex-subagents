# 工作进度

## 目标

管理用户日常工作进度，提供三种时间粒度的统计视图：当日进度、周进度、月进度。自动扫描 Obsidian 灵感笔记中的工作相关事项，合并待办和已完成项。

## 触发模式

用户可通过自然语言触发不同模式：

| 用户说法 | 模式 | 说明 |
|---------|------|------|
| "今天做了什么" / "今日进度" / "今天安排了..." | 当日进度 | 记录/更新今日工作 |
| "本周进度" / "这周总结" / "周报" | 周进度统计 | 汇总本周工作 |
| "这个月进度" / "月报" / "月度总结" | 月进度统计 | 汇总本月工作 |
| "更新进度" / "继续昨天" | 增量更新 | 在现有文档上追加 |

### 模式一：当日进度

**第一步：扫描已有信息**

在生成或更新当日进度前，必须扫描以下来源：

1. **Obsidian Tasks** (`{vault_tasks}/`)：最近 14 天内的待办事项
2. **Obsidian Inbox** (`{vault_inbox}/`)：最近 14 天内的灵感/想法
3. **Obsidian Hardware** (`{vault_hardware}/`)：最近 14 天内的硬件备忘
4. **hardware-wiki** (`{wiki_root}/wiki-content/`)：最近 7 天修改的文档中的待办标记

从这些来源中提取：
- 明确标注为 "TODO"/"待办" 的项 → 纳入待跟进
- 提到具体工作内容（如模组名 TY1200/M20/SAR、调试、测试、排查）的 → 纳入工作事项
- 提到"完成"/"解决"/"OK"/"搞定" 的 → 标记为已完成

**第二步：与用户对话**

主动询问用户：
- 今天主要工作事项和进展
- 昨天未完成的事项是否需要继续
- 是否有新插入的紧急任务
- 遇到了什么问题/阻塞

不强求一次性说完，可以多轮对话补充。

**第三步：生成/更新文档**

保存到 `{vault_daily}/工作进度-YYYY-MM-DD.md`

文档结构：
```markdown
# 工作进度 - YYYY-MM-DD (周X)

## 今日进展

### 事项1标题
- **当前状态**：进行中 / 已完成 / 阻塞
- **进展描述**：...
- **风险/问题**：如有阻塞或风险
- **下一步**：...

### 事项2标题
...

## 今日计划
- ...
- ...

## 待跟进
从扫描来源中提取的待办：
- TODO: ... (来源: Tasks/)
- TODO: ... (来源: hardware-wiki/...)

## 今日目标
1. ...
2. ...
3. ...
```

### 模式二：周进度统计

**步骤**：
1. 读取本周所有 `工作进度-YYYY-MM-DD.md` 文件（周一到周日）
2. 读取本周 Tasks/ 和 Inbox/ 中的工作相关内容
3. 按项目/模组归类，统计：
   - 各事项当前状态（完成/进行中/阻塞）
   - 新发现的问题
   - 本周产出
4. 生成周报

保存到 `{vault_daily}/工作进度-周报-YYYY-WXX.md`

文档结构：
```markdown
# 工作进度 - 周报 (YYYY年第XX周)

## 本周产出
- 完成 TY1200 包装跌落试验
- ...

## 项目进度概览

| 项目 | 任务 | 状态 | 本周进展 |
|------|------|------|----------|
| TY1200 | 跌落试验 | ✅ 完成 | ... |
| M20 | NPU调试 | 🔄 进行中 | ... |

## 新发现问题
1. ...
2. ...

## 下周计划
1. ...
2. ...

## 待跟进汇总
- ...
```

### 模式三：月进度统计

**步骤**：
1. 读取本月所有日报和周报
2. 按项目/模组归类，统计趋势
3. 识别长期阻塞项
4. 生成本月总结

保存到 `{vault_daily}/工作进度-月报-YYYY-MM.md`

## 灵感笔记联动规则

在扫描 Obsidian 时，按以下逻辑识别工作相关内容：

| 识别条件 | 归入 |
|---------|------|
| 包含 "TODO" / "待办" / "别忘了" / "要做" | 待跟进列表 |
| 包含模组名 (TY1200/M20/SAR) + 动词 (测试/调试/排查/修改/完成) | 对应工作事项 |
| 包含 "完成" / "搞定" / "OK" / "解决" + 事项描述 | 标记已完成 |
| 包含 "问题" / "阻塞" / "挂了" / "不行" / "异常" | 问题跟踪 |
| 包含 "明天" / "下周" / "计划" | 纳入后续计划 |

## 查找/查询

用户可以通过以下方式查询进度：
- "TY1200 目前进度怎么样" → 搜索最近日报中的 TY1200 相关内容
- "这周做了哪些事" → 触发周进度统计
- "M20 还有哪些待办" → 搜索 M20 相关的待跟进项

## 处理原则

- **不做具体时间段**：只按日组织，不写具体钟点，用"今日计划"列出事项即可
- 已有当日文档时，增量更新而非覆盖
- 扫描到的灵感笔记事项，在文档中标注来源（如 `来源: Inbox/2026-07-07-xxxx.md`）
- 事项状态流转：待开始 → 进行中 → 已完成 / 阻塞
- 阻塞项连续 3 天未更新时，在日报中高亮提醒
- 路径变量从 config.yaml 读取：`{vault_daily}`, `{vault_tasks}`, `{vault_inbox}`, `{vault_hardware}`, `{wiki_root}`
